# Telegram Blorg for Android

Telegram Blorg is a productivity-focused messaging space built on [Telegram Android source](https://github.com/DrKLO/Telegram).

## Features

A complete list of features, improvements, and changes is available in the [CHANGELOG.md](CHANGELOG.md) file.

## Download

The latest version is available on the [GitHub Releases](https://github.com/dmytro-varich/Telegram-BLORG-Android/releases/latest) page.

You can also download the latest APK directly [here](https://github.com/dmytro-varich/Telegram-BLORG-Android/releases/latest/download/telegram_blorg.apk).

All releases are automatically built and published using GitHub Actions.

## Contributing

Contributions are welcome and greatly appreciated.

If you would like to contribute to the project:

1. Fork the repository.
2. Create a new branch for your changes.
3. Commit your changes with clear and descriptive messages.
4. Open a Pull Request describing your changes.

Please ensure that your code follows the existing project structure and coding style.
